synthetic [`workbook.pdf`](workbook.pdf) (invented text, with an answer key on the last page) and the output is what the tool
printed (paths shortened to `.`). The concepts are in chapter 14 of the [agent guide](../../docs/AGENT_GUIDE.md). The end state is

(the batch), [`workbook.mcbundle`](workbook.mcbundle) (the bundle for the Android app) and

## 8. Applying the same batch again duplicates nothing: an exercise is identified by its section and label, so the second time is an error and nothing is written.

```console

  hint: An exercise is identified by its section and label, so applying a batch twice adds nothing twice. Add "replace": true (--replace) to overwrite it in place, or choose another label.
(exit code 4)
```

## 9. Authoritative exercises are single exercises: they are never cut into parts. The error explains the convention.

```console
$ mcprep frames split 1.1:3a --at 0.5
mcprep: error [E_AUTHORITY] Operation 0 (split): f3 is an authoritative exercise (1.1:3a), so it cannot be cut into parts.
  hint: An authoritative exercise is one exercise with one printed label. The parts of a printed exercise (5a, 5b) are separate exercises with separate labels, and what they share (the statement printed once above them) is attached to each of them as context (`context add`). Cutting into parts is for exercises you frame for yourself.
(exit code 4)
```
