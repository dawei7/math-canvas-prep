# Dependencies and licences

Only MIT, Apache-2.0, BSD, ISC and similarly permissive licences are used. The tools make no network calls. No licence has been
chosen for this repository's own code yet.

## What the tools need

| Dependency | Used by | Licence | Why |
| --- | --- | --- | --- |
| `pdfjs-dist` 5.6.205 | core (CLI, MCP, desktop) | Apache-2.0 | Reading PDFs: pages, text, outline, rendering. Pinned to the last 5.x line that runs on Node 20.19. |
| `@napi-rs/canvas` 0.1.100 | core | MIT | Prebuilt canvas (no system libraries) for rendering pages and crops to PNG. Optional at run time: without it only `render`/`crop` and the ink analysis of `propose` fail. |
| `@modelcontextprotocol/sdk` | mcp | MIT | The MCP server over stdio. |
| `zod` | mcp | MIT | Input schemas of the MCP tools (a peer of the SDK). |
| `electron` | desktop | MIT | The desktop app. |
| `preact` | desktop | MIT | The editor's user interface (bundled). |

Everything else in the core is written for this repository on Node's own libraries: the ZIP codec, the PDF writer used by the
tests, the JSON schemas' checks.

## What building, testing and packaging need (development only, never shipped in a bundle)

| Dependency | Licence | Why |
| --- | --- | --- |
| `typescript` | Apache-2.0 | Compiler (strict mode). Pinned to 5.9, which `typescript-eslint` supports. |
| `vitest` | MIT | Tests (3.2 line: runs on Node 20). |
| `eslint`, `@eslint/js`, `typescript-eslint` | MIT | Linting. |
| `@types/node` | MIT | Node typings (20 line, so that no newer API is used by accident). |
| `ajv` | MIT | Checks the JSON schemas against fixtures in the tests. |
| `esbuild` | MIT | Bundles the desktop app. |
| `electron-builder` | MIT | Packages the desktop app. |
| `playwright-core` | Apache-2.0 | Drives the Electron app for the end-to-end test and screenshots (no browser download). |
